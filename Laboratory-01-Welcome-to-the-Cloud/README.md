This laboratory activity introduced me to the Linux environmen-t and basic cloud computing concepts. I explored an Ubuntu 24.04 environment, checked system information, created a workspace, and documented my activities using Markdown and GitHub.

- Identify basic system information.
- Create and organize directories and files.

- Create and edit Markdown files.
